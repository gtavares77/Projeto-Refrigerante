# 🥤 DevClub Refri

Aplicação web interativa que simula um carrossel de sabores de refrigerante, desenvolvida com HTML, CSS e JavaScript.

O projeto apresenta diferentes sabores (Morango, Abacate e Laranja), com navegação dinâmica entre os itens, animações suaves e um design moderno baseado em cores personalizadas para cada slide.

## ✨ Funcionalidades

* 🔄 Carrossel interativo de itens
* 🎨 Mudança dinâmica de cor de fundo
* 🖼️ Sobreposição de imagens (fruta + lata)

* 🧠 Interação com JavaScript (manipulação de classes)
